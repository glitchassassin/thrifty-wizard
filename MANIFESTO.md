# Manifesto

The Thrifty Wizard's Guide should reflect wisdom, integrity, and diligence. Therefore:

1. We disclose affiliations clearly and don't allow sponsors to influence our recommendations
2. We prioritize popular and maintained open-source projects over paid products
3. We support claims with evidence, differentiating between studies; experiments; and popular opinion
4. We present today's best practices, not banking on future capabilities
5. We explain tradeoffs and failure modes clearly without dramatic FUD
6. We accept suggestions and corrections via [GitHub Issues](https://github.com/glitchassassin/thrifty-wizard/issues)

## AI Usage Policy

We use generative AI tools to:

- build and maintain the site's code
- assist human code review
- create images
- review and fact-check content
- identify out-of-date content

We do not use generative AI tools to:

- write user-facing content
- communicate via email or social media
